Who can sign in

Everyone needs an account to open the site. Reps can use the matrix and make RFQs. Quoters (inside sales) see every rep’s RFQs, attach the quotes and comment, but can’t change burners. Editors can see every RFQ and change burners and cross-references. Admins can also add and remove people. Name, phone and email fill in “Prepared by” on RFQs; people can change their own from My profile on the main page.

Settings

The address the Email PDF button fills in for every RFQ. Separate several with commas. Reps can still change it on a single RFQ. Leave blank to use the container's RFQ_TO setting.

An RFQ that's Emailed or Quoted gets flagged “Follow up” after this many days with no activity (no email, status change or “Followed up” click). Use 0 to turn reminders off.

Appliance specs

Each brand's guide of which burner setup fits which boiler or furnace model. Reps search it from Look up an appliance or burner on the matrix page and can start an RFQ with the spec filled in. Load it from the guide's CSV export; the columns can be in any order as long as there's an appliance maker, appliance model and burner model column.
